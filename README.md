# ma-jong-AI — 雀魂ルールの麻雀AI + 打牌レビュー

雀魂(段位戦)ルールの四人麻雀を対象に、(1) 自己対戦エンジン、(2) 打牌AI、(3) **「あなたの選択が間違っているか」を解説するレビュー機能** を実装したものです。

## 現状(正直な報告)
- **目標の「雀魂で平均順位2.4」は未達成・未検証です。** 以下はすべて、このリポジトリ内のシミュレータでの自己対戦の数字で、雀魂の人間相手の成績とは比較できません。
- 調整済みAI(`majai/best_params.json`)の平均順位(席は回転、600局、±0.04〜0.05):
  - 素朴bot3人 相手: 2.17
  - 強い素朴bot(`efficiency+`)3人 相手: 2.48 (ほぼ互角。強い素朴botが意外に強い)
  - 調整前の既定値AI 3人 相手: 2.38
- パラメータ探索(`scripts/tune.py`、約1時間)で、探索に使っていない1600局の検証では、調整前2.43 → 調整後2.31 に改善しました。
- 人間相手でこれが通用するかは不明です。特に、攻撃寄りに調整されたこと(将来の放銃リスクを見ない等)は、相手がシミュレータ内のbotだから有利になった可能性があります。
- 人間の高段位の牌譜を使った学習(後述のロードマップ)は、この環境ではできません。

## 強い素朴botの戦術の取り込みとリーグ戦(結果)
- `efficiency+` の戦術(聴牌即立直・強制オリ・危険牌を押さない・役牌ポン/役確定の鳴き)をAIのパラメータとして実装しました(`riichi_bias` `fold_shanten` `push_danger_limit` `yakuhai_pon_force` `sure_yaku_call_force`、既定はオフ)。
- 単純に全部オンにすると逆効果でした(強い素朴bot3人相手、800局): 調整済み2.44 → 強制オリ追加 2.55、全部追加 2.59。
- チャンピオン更新リーグ(`scripts/league.py`、3世代・各約1時間)では、挑戦者(1人)対チャンピオン(3人)の新しい配牌2000局で、3世代とも互角(2.50〜2.54位)で、採用された挑戦者はありませんでした。**パラメータの調整では、現チャンピオン(`majai/best_params.json`)を超えられない**というのが結論です。
- 改善には評価式そのもの(和了確率・打点・守備の見積りの作り)の改良が必要と考えられます。

## 使い方
```
pip install mahjong numpy pytest
python scripts/evaluate.py --games 300 --hero majai --vs efficiency+   # 自己対戦で平均順位を測る(--vs mix も可)
python scripts/tune.py --rounds 4 --pop 24                 # パラメータ探索(約1時間。--resume で再開、scripts/checkpoint_push.sh で途中結果をpush)
python scripts/review.py --demo --seed 5                   # 自己対戦ログをレビューするデモ
python scripts/review.py game.jsonl --player 0             # mjai形式の牌譜を席0視点でレビュー
pytest -q tests
```
レビューは、打牌・立直/ダマ・チー/ポンについて AI の推奨と実際の選択を比べ、損失(点数換算)の大きい順に、
シャンテン後退・受け入れ枚数・打点(ドラ/役牌/赤を切った等)・放銃率(現物/筋)・押し引きの観点で理由を表示します。
損失の絶対値はAIの簡易モデルによる概算なので、**順位付けと理由を参考に**してください。

牌譜は mjai 形式(JSON Lines)です。天鳳/雀魂の牌譜は mjai-reviewer などの変換ツールで mjai 形式にできます(本リポジトリに変換器は未収録)。

## 構成
- `majai/shanten.py` 高速シャンテン(参照ライブラリと一致をテスト済)
- `majai/state.py` mjaiイベント→視点別の局面復元(河・現物・副露・ドラ・立直状況)
- `majai/agent.py` 打牌/鳴き/立直の評価 (和了確率×打点 − 放銃確率×失点、押し/オリ自動判定)
- `majai/engine.py` 雀魂ルールの対局シミュレータ(mjaiログ出力)
- `majai/review.py` レビューと日本語解説
- 実装済ルール: 25000点持ち、東南+西入、赤3枚、喰いタンあり、ダブロンあり(トリロンは流局)、トビ終了、オーラスのアガリ止め、供託・積み棒、フリテン(同巡/立直後フリテンは未対応)
- **カン対応**: 暗槓・加槓・大明槓、嶺上開花、槍槓(加槓)、カンドラ(暗槓は即時/明槓・加槓は打牌後)、四開槓流局、立直後の暗槓(待ちが変わらない場合のみ)。
  AIのカン方針は保守的です: 他家の立直・3副露などの脅威があれば見送り、手が3シャンテン以上なら見送り、シャンテンが後退するなら見送り、門前での大明槓はしない、オーラスでトップ目なら見送り(立直中の暗槓は常に実行)。
  レビューにもカンの判断(した/しなかった)が出ます。カンの損失額は固定の目安値です(他の判断のようなEV計算ではありません)。
- **未実装**: 流し満貫、途中流局(九種九牌・四風連打・四家立直)、パオ、暗槓への国士槍槓。

## 2.4 を目指すロードマップ
1. 人間の高段位ログ(天鳳鳳凰卓など)を mjai 形式で集め、`StateTracker` の状態を特徴量化。
2. 打牌/鳴き/立直の方策ネットワーク(PyTorch)を教師あり学習 → 自己対戦で強化学習。GPU が必要。
3. `AIPlayer` と同じ `discard()/call()` を持つ `NNPlayer` を追加し、`scripts/evaluate.py` で比較。レビュー機能は評価器を差し替えるだけで同じ形式の解説が出せる(解説理由の生成はルールベースのまま併用)。
4. 現在のヒューリスティックはその教師・ベースラインとして使える。
